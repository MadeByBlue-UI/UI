		  le décalage mesuré est verrouillé (seul un clic qui le contredit de plus de 14 px le change). « Copier le journal du curseur » liste qui a
		  modifié la correction et de combien (Library:GetPointerLog()). Library:CalibratePointer() lance le calibrage par script.
		• SYSTÈME DE POINTEUR REFAIT DE ZÉRO (V9.13) : un seul point d'entrée Library._pointerPos(p) pour souris / curseur virtuel / doigt. BUG corrigé :

	FLUIDITÉ
		• BOUCLE D'ANIMATION PARTAGÉE (Library.Ticker) : une seule connexion Heartbeat pour tout (fond, étoiles, graphiques,
		  ressorts, défilement, couleurs, chiffres, repli des blocs, FPS). Chaque tâche a sa cadence (rate) et un « gate » :
		  elle dort quand rien ne bouge ou quand son élément est caché ; la fenêtre Roblox sans focus met le décoratif en pause ;
		  si tout dort, la connexion est coupée. Le FPS est mesuré une seule fois (Library.Ticker.Fps).
		  Pour tes propres animations : local h = Library.Ticker.connect(function(dt, now) ... end, { rate = 30, gate = monFrame })
		  puis h:Disconnect() quand c'est fini.
		• Le fond animé (anneaux + étoiles) n'est plus recalculé à chaque frame : boucle Heartbeat à ~30 Hz
		  (~15 Hz pendant un geste), au lieu de RenderStepped + pause/reprise brutale (c'était la cause de l'effet « 15 fps »).
		• RenderStepped ne gère plus que le déplacement / redimensionnement (très léger). Le redimensionnement suit
		  directement le curseur (moins de recalculs de layout), le déplacement reste lissé.
		• tween() met les TweenInfo en cache ; le slider se met à jour sans tween empilés pendant le glisser ;
		  le dropdown ne ré-anime que les lignes qui changent. Bug corrigé : l'appel de glisser sans position.
